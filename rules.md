## Who can enter

- Anyone at the age of majority where they live. Solo is fine. No team size limit.
- Not open to residents of Brazil, Quebec, Russia, Crimea, Cuba, Iran, North Korea or other places under full US sanctions.
- Not open to PayPal or Devpost staff, judges, or their families.
- Being able to open a PayPal account is a separate question from being eligible (FAQ).

## What to build

- An app that uses the **PayPal developer platform in the free sandbox** and **an AI tool, model or platform**. Any AI tool works, "as long as PayPal integration is central to the project."
- Must meaningfully use at least one PayPal API, SDK or product, and meaningfully use AI.
- Must be a working prototype. A mockup or a non-working demo fails.
- New or existing projects. An existing project must be "significantly updated" after Oct 1, and the entry should say what changed.
- Any third-party SDK, API or data must be used within its terms.

## What to submit

1. **Text description** of features and how it works.
2. **Tools used**: name each AI model or service and how it was used.
3. **Working demo**: either clear setup and run instructions in the repo that judges can follow, or a hosted URL.
4. **Public code repo** on GitHub, GitLab or Bitbucket. It must hold all source code, assets and instructions needed to run. It must carry an open-source license file that GitHub shows at the top of the repo page.
5. **Demo video**: under 3 minutes (judges may stop at 3:00), public on YouTube, link on the form. Must show the project working on its intended device (a screen recording of a laptop is fine). **No third-party trademarks or copyrighted music without permission.**
6. **Testing access**: free and unrestricted until judging ends. Include any test credentials, API keys or sandbox login details needed, or clear steps to get them.
7. English, or English translations of everything.

## How it is judged

- Stage one, pass or fail: does it fit the theme and really use the PayPal APIs.
- Stage two, five criteria with equal weight:
  - **Technological implementation**: how well it uses PayPal and the AI tools; real, non-trivial work.
  - **Design**: a complete product experience, not only a technical proof.
  - **Potential impact**: a specific, believable problem for a real audience, solved by what the demo shows.
  - **Innovation**: how new the idea is.
  - **Presentation**: does the video show it working end to end, and say what problem, for whom, and why.
- Ties go to the higher score on the criteria in the order above.
- Judging may use expert panels, peer review or "automated AI-driven analysis."

## How this changed the plan

The working idea (PayPal pay-per-call for AI agents) fits the rules. These changes come from the rules:

1. **Deadline is 12:00 pm PT, not 2:00 pm.** Plan to submit by the evening of Nov 11.
2. **The repo must run on its own.** It cannot depend on the private Plainfeed feed code. So the repo ships a mock PayPal mode and a small sample dataset. Real Plainfeed data is optional, through a proxy setting that holds the seller's own feed key.
3. **Judges need a way to test.** Mock mode needs nothing. For sandbox mode, the README explains how to get sandbox keys, and the Devpost testing notes can include a sandbox buyer login (fake money only). Never put keys in the repo.
4. **AG Grid is cheap to qualify for.** The ledger page uses the free AG Grid Community grid, which counts as "any AG Grid tools". Winning that prize would need AG Studio with its trial license.
5. **APIMatic needs Olu's hands.** Qualifying means using the APIMatic Context Plugin while building the PayPal part. That installs a plugin into his coding agent, so it is his step, not done here.
6. **Render prizes are credits, not cash.** Skipped unless he wants a hosted demo URL there.
7. **Video rule on trademarks and music.** No music unless licensed. Keep logos out of frame where possible; the PayPal sandbox checkout screen is fine because PayPal runs the contest.
8. **Name the AI tools.** The submission text must list Claude (the buying agent, through MCP) and Claude Code (used to write the code).
