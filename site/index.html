Plainfeed Agent Pay

AI agents can buy data here one call at a time. They pay with PayPal, and their person approves every payment.

LedgerPricesHealth

How a purchase works

  1. The agent asks for data. Paid calls answer 402 Payment Required with a price quote.
  2. The agent puts all the calls it needs into one quote. The gateway checks the agent's spending limits.
  3. The gateway creates a PayPal order. The agent shows its person the link.
  4. The person approves in PayPal. The gateway captures the payment.
  5. The agent gets the data and a signed receipt. The seller's ledger gets one plain-English line.

Connect Claude

Claude Code, with this server running:

claude mcp add plainfeed-pay -e GATEWAY_URL=http://localhost:8787 -e AGENT_KEY=demo-agent-key-not-secret -- node /path/to/plainfeed-agent-pay/src/mcp/stdio.ts

Then ask: "Compare the cost of a travel day in Lisbon and Madrid. You can spend up to 20 cents."
